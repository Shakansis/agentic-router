## Defects found and corrected

1. Evidence was originally captured before supervisor inference and could be accepted
   after the artifact changed. The Host now recaptures evidence immediately before an
   accepting decision and rejects a stale revision.
2. Reloading a persisted conversation left a live supervised run detached and displayed
   a generic interrupted warning. The browser now finds the conversation-linked run,
   attaches through a replayable Chat SSE projection, and persists the terminal answer.
3. The deterministic provider fixture did not recover after a write was rejected for
   missing inspection. It now changes strategy to read, then write, then reread.

Exploratory blocked runs were retained as diagnostic evidence but are not counted as
accepted cases. In particular, malformed canonical supervisor JSON was blocked without
an identical retry, and an internally inconsistent byte-count criterion was not
silently accepted.
