# v0.9.8 implementation decisions

## Scope decisions

- Search remains a literal scan of bounded local session records. No model,
  embedding index, cloud request, or background inference is used.
- Search snippets are created only from persisted user-visible fields and
  bounded execution metadata. Hidden prompts, raw tool results, approval state,
  and unrestricted process output are not search sources.
- Pinned conversations are presented separately and are skipped by automatic
  retention cleanup. Explicit confirmed deletion remains authoritative.
- Summary estimation performs model discovery and token estimation but no
  inference. Generation requires both explicit confirmation and permission for
  the selected provider or GPU on every request.
- Summary facts contain complete visible user/assistant turns plus bounded
  changed-file and validation facts. The structured summary is stored outside
  the original message list so edit, regeneration, and deletion do not rewrite
  conversation history.
- Duplicates receive a new Host-generated ID and derived title, start in Chat
  mode, and discard model lock, execution reviews, rollbacks, approvals,
  processes, pin/archive state, interruption, and runtime authority. An
  existing preferred global profile reference and optional summary may be
  copied.
- Markdown export is a separate readable format. Likely credentials and
  absolute Windows paths are redacted, execution data is bounded, and internal
  approval/process authority is excluded.
- Context usage counts the current user request as visible and included. The
  initial event is estimated; a terminal provider token count replaces only
  the input-token accuracy while preserving the Host-owned inclusion and limit
  breakdown.

## Verification decisions

- The automated suite continues to replace providers only at their external
  HTTP boundary. New tests exercise the real browser, API, persistence, search,
  retention, summary, duplication, export, and streaming paths.
- No real Ollama model or cloud provider was invoked while closing v0.9.8
  because those tests require the user's per-run permission.
