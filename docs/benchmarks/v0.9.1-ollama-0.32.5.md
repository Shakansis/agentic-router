# Agentic Router v0.9.1 real Ollama benchmark

## Scope

This benchmark was executed on 2026-07-30 in the `America/Sao_Paulo` time zone
(2026-07-31 UTC) against every model reported by the configured local Ollama
instance.

- Benchmark: `TOOL_PROTOCOL_CONFORMANCE_V1`
- Ollama: `0.32.5`
- GPU: NVIDIA GeForce RTX 4090, 24,564 MiB, driver 610.88
- CPU: AMD Ryzen 9 5900X
- RAM: 79.9 GB
- Context: 40,960 tokens
- Maximum tool output: 2,048 tokens
- Temperature: 0
- Generation timeout: 300 seconds per probe

The benchmark is synthetic and non-executing. It verifies:

1. one native `benchmark_echo` call;
2. one nested `benchmark_plan` call with an objective and two titled steps;
3. one native `benchmark_read` call;
4. a tool-result continuation followed by one native `benchmark_edit` call.

A PASS means only that the exact model digest completed this native tool
protocol under the recorded Ollama version. It is not a general model-quality
score. A different digest, model tag, Ollama version, prompt, or tool schema
requires a new run.

## Configuration implications

- `qwen3:1.7b` can remain a lightweight intention router, but this digest must
  not coordinate native tools directly.
- `qwen3-coder:30b` passed all probes and is eligible for the coordinator role
  for this exact digest and Ollama version.
- `qwen3.6:latest` passed while `qwen3.6:27b` timed out. Tags and digests must
  not be treated as interchangeable.
- Both installed `gpt-oss` variants failed the read-result-edit cycle and must
  not receive direct coordination for this environment.
- Failed models may still be used for non-tool chat or specialist work. The
  Host must route tool coordination through a conformant coordinator.

## Reproduction

Run the Release Host against the intended Ollama instance, then execute:

```powershell
.\scripts\run-real-tool-protocol-benchmark.ps1 `
  -BaseUrl http://127.0.0.1:5294 `
  -TimeoutSeconds 1500
```

The runner processes models sequentially, records JSON and Markdown under the
ignored `artifacts/benchmarks/` directory, and restores the resident router
after the last model.
