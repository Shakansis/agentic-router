# v0.10.0 alpha real acceptance

Date: 2026-08-31

This document separates user-observed real integration evidence from
deterministic fake-provider coverage and package verification.

## User-observed AnythingLLM acceptance

The configured local AnythingLLM server was used through Agentic Router with
project Knowledge/RAG enabled. The user reported successful grounded answers for
the original Durham question and two additional knowledge questions.

This confirms the intended real path from a selected project library through
AnythingLLM retrieval into Agentic Router-managed inference context. AnythingLLM
did not own routing, model selection, generation, execution, or persistence.

Exact trace IDs and model/harness identities were not captured in this document,
so this evidence is classified as user-observed manual acceptance rather than a
reproducible trace bundle.

## Overnight integrated project run

The user ran a 15-step project plan throughout the night. The report states that
all steps completed and validated successfully and that the run exercised the
AnythingLLM integration along with the broader integrated product behavior.

This is long-running manual soak evidence. It is not a substitute for the full
deterministic Playwright suite, publish-artifact verification, or platform
package smoke tests.

## Explicitly separate evidence

- Manual Benchmark Lab acceptance was not included in the overnight run and was
  still pending when this release gate began.
- Real cloud-provider acceptance was not part of this report.
- Physical Linux hardware acceptance was not part of this report; WSL package
  smoke, when executed, remains a separate and weaker platform category.
